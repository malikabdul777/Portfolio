Selected Work

Email performance dashboards

I built an email performance dashboard that collects webhook events from SendGrid, Postmark, and Resend and organizes them into clear, detailed reports. It brings together individual event logs, sending-domain performance, and delivery trends across mailbox providers like Gmail and Outlook, so I can spot issues and recurring patterns at a glance without digging through events one by one.

Unsubscribe & suppression platform

A platform I developed for one-click unsubscribe workflows and suppression management. It brings recipient preferences and email operations together, with public unsubscribe routes and an authenticated admin portal. Built with React and TypeScript.

Email Builder

I built a drag-and-drop email template builder that makes it easier to design responsive HTML emails without starting from code. Arrange text, images, buttons, and columns, edit content inline, and check desktop and mobile previews as you work. Save and reuse templates, export the HTML, or import and export JSON to keep editing. A built-in code editor also supports direct HTML editing.
